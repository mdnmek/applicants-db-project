# 🎓 База данных приемной комиссии университета (University Admissions DB)

Пет-проект по проектированию и работе с реляционной базой данных на PostgreSQL. Проект моделирует логику работы приемной комиссии вуза: учет факультетов, образовательных программ, предметов ЕГЭ, абитуриентов, их баллов и индивидуальных достижений.

## 📋 Описание проекта

База данных позволяет хранить и обрабатывать информацию, необходимую для процесса поступления:
- Список факультетов и образовательных программ с указанием плана набора.
- Перечень предметов ЕГЭ, необходимых для поступления на каждую программу, и минимальные проходные баллы.
- Данные об абитуриентах, их результатах ЕГЭ и индивидуальных достижениях (медали, значки ГТО).
- Связь абитуриентов с выбранными программами и наличие у них достижений.

## 🛠️ Стек технологий

- **СУБД:** PostgreSQL
- **Инструмент администрирования:** pgAdmin 4
- **Язык запросов:** SQL

## 🗄️ Структура базы данных

База данных состоит из 9 таблиц, связанных между собой внешними ключами (Foreign Keys).

### Основные сущности:
- `department` — Факультеты (Инженерная школа, Школа естественных наук и т.д.).
- `subject` — Предметы ЕГЭ (Русский язык, Математика, Физика, Информатика).
- `program` — Образовательные программы (Прикладная математика, Мехатроника и т.д.).
- `enrollee` — Абитуриенты.
- `achievement` — Индивидуальные достижения и начисляемые за них баллы.

### Связующие таблицы (Many-to-Many):
- `program_subject` — Предметы ЕГЭ, необходимые для каждой программы, и минимальные баллы.
- `program_enrollee` — Выбор абитуриентами образовательных программ.
- `enrollee_subject` — Результаты ЕГЭ абитуриентов по конкретным предметам.
- `enrollee_achievement` — Достижения, имеющиеся у абитуриентов.
